
# Начало работы с проектом

Добро пожаловать! Следуйте этой инструкции, чтобы быстро развернуть проект на своем локальном компьютере.

---

## 🛠 Установка и запуск

Для работы вам понадобится установленный **Git**. Выполните следующие шаги в терминале (рекомендуется **Git Bash**):

### 1️. Подготовка папки
Создайте новую директорию для проекта и откройте в ней терминал.

### 2️. Клонирование репозитория
Скопируйте и вставьте следующие команды:

```bash
# Инициализация (необязательно, если сразу делаете clone)
git init

# Загрузка проекта
git clone https://github.com/SeregaPl/Project.git

```

### 3️. Переход к настройке данных

Основная конфигурация и работа с данными находятся в отдельном модуле.
Перейдите в папку data с данными.

> После перехода в `data/`, откройте находящийся там файл **README.md** для получения инструкций по настройке окружения и базы данных.
